# 🎉 Money Transfer Frontend - React Application

Welcome! This is a **modern React frontend** for a money transfer application.

---

## 🚀 Quick Start (2 Steps)

### Step 1: Install
```bash
cd frontend
npm install
```

### Step 2: Run
```bash
npm run dev
```

**Open**: http://localhost:3000
