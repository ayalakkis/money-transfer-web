## 💡 Pro Tips

### Use Sneat Colors
```jsx
// Purple primary
className="bg-primary-600 text-white"

// Success badge
className="badge badge-success"

// Info card
className="bg-info-50 border-info-200"
```

### Sneat Spacing
```jsx
// Card padding
className="p-6"

// Section spacing
className="space-y-6"

// Button padding
className="py-2.5 px-5"
```

### Sneat Shadows
```jsx
// Small shadow
className="shadow-sm"

// Medium shadow
className="shadow-md"

// Hover effect
className="hover:shadow-md"
```
